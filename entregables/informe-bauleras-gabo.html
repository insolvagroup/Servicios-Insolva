Bauleras Self-Storage

Informe para Gabo

Proyecto: 32 bauleras de self-storage en Ushuaia. Cliente Daniel Feldman. No se desarrolla sistema propio — se busca un SaaS existente y DEVXIA construye el gateway de integración con cámaras y cerraduras.

Hardware confirmado

  • Cámaras Hikvision con protocolo ISAPI (snapshots check-in/check-out)
  • NVR graba 24/7
  • Cada baulera con motor WiFi (nodos de exterior)
  • Apertura: a definir — Tuya STW-GARAGE vs Hikvision DS-K (decide Gabo/Marcos según presupuesto)

¿Qué tiene que hacer el software?

  1. Gestión de clientes, contratos, reservas y bauleras — portal de autogestión para inquilinos
  2. Motor de autorización — quién abre qué y cuándo
  3. Check-in/check-out con snapshot de cámara automático
  4. Trazabilidad y auditoría de eventos y aperturas
  5. Integración con cámaras Hikvision ISAPI + cerraduras Tuya/DS-K
  6. Pagos online (Mercado Pago vía gateway DEVXIA)
  7. Facturación AFIP/ARCA (módulo extra a definir)

Comparativa de software

🏆 Ganador recomendado

🏪 Storeganise

Lo que ofrece de base:

  • API abierta + webhooks ilimitados
  • Integración con candados electrónicos (PTI, Nokē, OpenTech)
  • Portal de cliente con reservas, pagos online y e-sign
  • Website builder + SEO + AI booking assistant
  • Dashboard analítico exportable a CSV/Excel/PDF
  • Add-ons marketplace con 35+ integraciones
  • Precios dinámicos por ocupación
  • Opera en 50+ países, 350+ operadores
➕ Lo que agrega DEVXIA: Gateway de integración Hikvision ISAPI (snapshots) + Tuya/DS-K (apertura) + Mercado Pago + facturación AFIP/ARCA

📦 Unit Trac

Lo que ofrece de base:

  • API disponible (webhooks no confirmados)
  • Gestión de clientes, reservas, facturación básica
  • Económico: desde USD 30/mes
➕ Lo que agrega DEVXIA: Gateway completo (Hikvision + Tuya/DS-K + Mercado Pago + AFIP) + posiblemente polling si no hay webhooks

📊 6Storage

Lo que ofrece de base:

  • API confirmada, pricing por unidad (~$0.75/unidad)
  • Módulo 6Security para control de acceso (~$75/mes extra)
  • Integra Nokē, Salto, PTI, OpenTech
➕ Lo que agrega DEVXIA: Gateway completo (mismo adapter que Storeganise)

Arquitectura propuesta — DEVXIA Gateway

[Storeganise] ←webhook→ [DEVXIA Gateway] → API call → [Hikvision ISAPI] (snapshot)
            ↓
            API call → [Tuya / DS-K] (apertura)
            ↓
            [Mercado Pago / AFIP] (facturación)

El SaaS no toca el hardware directamente. El gateway de DEVXIA recibe los eventos del SaaS (contrato activo, pago recibido, vencimiento), dispara comandos a las cámaras y cerraduras, y opcionalmente escribe eventos de vuelta al SaaS para trazabilidad unificada.
