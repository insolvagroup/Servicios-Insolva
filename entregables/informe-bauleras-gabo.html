Sistema de Gestión para Bauleras Self-Storage

Proyecto Daniel Feldman — Ushuaia, Tierra del Fuego

Resumen del proyecto

32 bauleras de self-storage en Ushuaia. Cliente Daniel Feldman. No se desarrolla sistema propio — se busca una plataforma SaaS existente y DEVXIA construye el gateway de integración con cámaras y cerraduras.

Hardware confirmado

  • Cámaras Hikvision con protocolo ISAPI (snapshots check-in/check-out)
  • NVR graba 24/7
  • Cada baulera con motor WiFi (nodos de exterior)
  • Candado físico por baulera (privacidad del cliente)
  • Apertura: a definir (Tuya STW-GARAGE vs Hikvision DS-K)

¿Qué tiene que hacer el software?

  1. Gestión de clientes, contratos, reservas y bauleras
  2. Portal de autogestión para inquilinos
  3. Motor de autorización (quién abre qué y cuándo)
  4. Check-in/check-out con snapshot de cámara
  5. Trazabilidad y auditoría de eventos

Opciones recomendadas

Unit Trac (~USD 30/mes)

  • API disponible (pendiente verificar si tiene webhooks reales)

Escenario B — Robusto

Storeganise (precio a confirmar)

  • API abierta + webhooks ilimitados
  • Ya modela integración con candados (PTI, Nokē, OpenTech)
  • Opera en 50+ países
  • Precio no público ("contact us"), estimado ~USD 99-150/mes
  • Sitio: storeganise.com

Alternativas consideradas

  • 6Storage (~USD 100/mes todo incluido): API confirmada, pricing por unidad (~$0,75/unidad + módulo 6Security ~$75/mes). Sitio: 6storage.com
  • Stora (UK, desde £99/mes): API pública, integra Nokē/PTI/Paxton. Sitio: stora.com
Nota: Ninguno de estos sistemas soporta Hikvision ISAPI, Tuya ni Hikvision DS-K de forma nativa. Los tres requieren que DEVXIA construya el gateway de integración. La decisión real entre ellos depende del presupuesto mensual de Daniel y la calidad del soporte.

Arquitectura propuesta — DEVXIA Gateway

El software de gestión SaaS no toca el hardware directamente. El gateway de DEVXIA actúa como puente:

[Storeganise/Unit Trac] <-webhook-> [DEVXIA Gateway] --> API call --> [Hikvision ISAPI] (snapshot)
                                          |
                                     API call --> [Tuya / DS-K] (apertura)
                                          |
                               [Mercado Pago / AFIP] (facturación)

El gateway:

  1. Recibe eventos del SaaS via webhook (contrato activo, pago recibido, vencimiento)
  2. Dispara comandos a cámaras (snapshot) y cerraduras (apertura/bloqueo)
  3. Opcionalmente escribe eventos de vuelta al SaaS para trazabilidad unificada
